# Interactive Quiz Application (Assignment 10)

## Overview
A lightweight, zero-dependency interactive quiz application developed using pure HTML5, CSS3, and JavaScript.

## Verified Test Matrix

| ID | Test Scenario | Expected Outcome | Status |
| :--- | :--- | :--- | :--- |
| **M1** | All 5 correct answers chosen | Score displays 5/5 | Verified |
| **M2** | All 5 incorrect answers chosen | Score displays 0/5 | Verified |
| **M3** | 3 correct, 2 incorrect | Score displays 3/5 | Verified |
| **M4** | Click same correct answer twice | Score counts only once | Verified |
| **M5** | After completing Question 4 | Final score not revealed | Verified |
| **M6** | Reload page | Score resets to 0 | Verified |

## Tech Stack
- HTML5 (Semantic document markup)
- CSS3 (Responsive card layout & Light/Dark theme switching)
- Vanilla JavaScript (DOM manipulation and state management)
